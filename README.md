# Viatto Page

Landing de Viatto (propuesta 3). Una sola página que se adapta al dispositivo:

- `index.html` y `styles.css`: la versión web (escritorio).
- `propuesta-3-movil.css`: los ajustes para celular. Solo se aplican en pantallas de hasta 600 px de ancho, así que en computador se ve la versión web y en celular la versión móvil.
- `assets/`: imágenes y animaciones.

Para verla en local, sirve la carpeta con cualquier servidor estático (por ejemplo `python3 -m http.server`) y abre `http://localhost:8000`. Abriendo `index.html` con doble clic funciona casi todo, salvo que el cangrejo no repite la animación del letrero al aparecer.

El formulario es de demostración: todavía no envía datos.
